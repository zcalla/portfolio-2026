명세는 데이터로, 실행기는 하나로

엔진 반영 실행기는 FX 적용기 1개로 한정. 작업 내용은 전부 JSON 명세로 관리. 신규 자동화는 실행기 수정 없이 명세 추가로 대응

작업 큐: JSON 명세→ 실행기 1개. FX 적용기→ 엔진 반영. 에셋 일괄 적용
IDEMPOTENT같은 명세 재실행 시 결과 동일. 중복 실행으로 인한 사고 방지
BACKUP적용 전 상태를 저장하고 시작
ROLLBACK실패 시 이전 상태로 복원

자동화가 바꾼 팀의 작업 방식

형식과 반복은 도구가 전담. 기획자의 시간은 설계와 검증으로 이동

✓무기 1종당 프로토타이핑 공수 15일 → 3일
✓데일리 보고서 작성 30분 → 1분
✓무기 1개 조립 인원 1명 이상 → 3개당 1명
✓스킬 하나 파악에 필요한 테이블 6종 이상 → 1종
✓Show 에셋 750개 자동 생성. 실측
✓검수 사양서 생성 비용 ≈ 0. 버튼 한 번
✓입력 오류 · 병목 감소
✓기획자는 설계와 검증에 집중
